# The work folder

Files that outlive a session belong in the shared FIU work folder, so the team can find them. Anything made elsewhere stays invisible to the team.

## 1. Where

If you know where the shared FIU work folder lives, check that the working folder sits inside it. If it does not, say once where the work belongs and that files made elsewhere stay invisible to the team; never block on it. If you do not know the work folder, skip this check silently.

If this session cannot write files (chat, mobile), say once that anything that must become a file needs a session in the work folder, and continue the thinking and drafting in the conversation.

## 2. Project folders

One folder per work cycle, named `YYYYMMDD-<topic>`, in a flat list: no folder per client. Create one only when a file must outlive the session; a session that only answers questions creates nothing.
